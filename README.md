# ما وراء القناع | Behind the Mask

لعبة غموض نفسي وتحقيق عربية قيد التطوير باستخدام Godot 4.4 Stable وGDScript. تستهدف Android، مع معاينة Web عبر GitHub Pages.

## الحالة
فصل الوصول قابل للعب من البداية إلى النهاية في البهو والمصعد وممر الطابق السابع والشقة 703. يتضمن لقاء الحارس والجار بأسماء مخصصة، ولغز تشغيل المصعد، وربط توقيتين متناقضين، وثلاث طرق لاختتام الفصل تتغير بحسب الثقة وسرية الرسالة. توجد أهداف داخل اللعبة، وحركة محددة بحدود الأرضية، ولوحة أرقام باللمس، وتوقف مؤقت وصوت أولي قابل للإيقاف.

الحفظ التلقائي موحد مع نسخة احتياطية واستيراد للتقدم القديم. نموذج التحقيق السابق ذو المناطق الثماني محفوظ ويمكن متابعة حفظه المستورد، بينما تبدأ الألعاب الجديدة بفصل الوصول دون كشف أسرار الفصول اللاحقة مبكرًا.

الرسوم والحركة والصوت مبدئية. الفصول الخمسة التالية، والإخراج 2.5D النهائي، والصوت التفصيلي، وأداء Android وAPK لم تكتمل بعد. التقرير السلوكي غير منفذ؛ المتاح فقط سجل إضافي اختياري يمكن إيقافه وحذفه.

## التصميم
- لعبة غموض نفسي في المبنى رقم 17، مع شخصيات رئيسية قابلة لتخصيص أسمائها.
- القرارات تؤثر في الأحداث والعلاقات والأدلة.
- التحليل السلوكي وصفي واختياري وليس تشخيصًا نفسيًا.
- حفظ محلي للبيانات، دون خادم.

## متابعة التطوير
افتح `project.godot` باستخدام Godot 4.4 ثم شغّل المشروع. تبدأ الجولة من البهو؛ لمس الأرض يحرك الشخصية ولمس العنصر يفتح الفحص بعد الاقتراب. اختيار إجراء التوثيق يضيف الدليل. دفتر التحقيق يسمح بقراءة الأدلة وتحديدها وربطها. الهدف الحالي ظاهر أثناء اللعب، واللغز يقدم تلميحًا ويمكن العودة إلى الأوراق في أي وقت. لا يلزم استخدام لوحة مفاتيح سوى إدخال أسماء اختيارية.

GitHub Actions يشغّل اختبارات مسارات التحقيق والحفظ ويصدر معاينة Web. نشر Pages يتم عند تحديث `main`. اقرأ [خطة التطوير وبنية الأنظمة وأوامر الاختبار](docs/DEVELOPMENT.md) للتفاصيل والحدود الحالية.

## الخصوصية والحقوق
الأسماء والتقدم والقرارات اللازمة للقصة تبقى في `user://` على الجهاز. السجل الإضافي للتقرير الوصفي يتطلب موافقة منفصلة، ولا توجد خدمات تحليل أو خادم. النماذج النصية والبهو القديمة محفوظة للمرجع وخارج مسار القائمة الأساسية. لم يُمنح ترخيص لإعادة استخدام محتويات المشروع بعد.
