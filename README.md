# ما وراء القناع | Behind the Mask

مشروع لعبة غموض نفسي تفاعلية قيد التطوير باستخدام Godot 4 وGDScript.

## الحالة
المستودع قيد التهيئة. النموذج الأولي 0.1 موجود كحزمة مشروع محلية، ولم تُرفع ملفات المصدر الكاملة بعد. لم يتم التحقق من تشغيله داخل Godot ولم يُنشأ APK.

## التصميم
- لعبة غموض نفسي في المبنى رقم 17، مع شخصيات رئيسية قابلة لتخصيص أسمائها.
- القرارات تؤثر في الأحداث والعلاقات والأدلة.
- التحليل السلوكي وصفي واختياري وليس تشخيصًا نفسيًا.
- حفظ محلي للبيانات، دون خادم.

## متابعة التطوير
تابع سجل Commits لتغييرات الملفات، وActions عندما تُضاف اختبارات البناء.

## الخصوصية والحقوق
لا تُرفع أسماء اللاعبين أو ملفات حفظهم. لم يُمنح ترخيص لإعادة استخدام محتويات المشروع بعد.
